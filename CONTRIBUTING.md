# Contributing

Thank you for contributing! Open an issue before large changes.

1. Fork the repository and create a focused branch.
2. Keep the renderer compatible with Python 3.10+ and the standard library.
3. Add or update tests for behavioral changes.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request describing motivation, changes, and example output.

Please avoid committing generated caches or proprietary assets.
